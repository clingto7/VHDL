# 硬件描述语言与系统仿真 · 学期实验 (2026 Fall)

硬件平台：STEP-MXO2 V2（小脚丫，Lattice LCMXO2-4000HC）+ STEP-Baseboard V2 底板
开发工具：Lattice Diamond 3.12 + ModelSim，全部代码使用 **VHDL**（要求：非 VHDL 得 0 分）

## 实验安排

| # | 实验 | 类别 | 分值 | 检测 |
|---|---|---|---|---|
| 一 | 矩阵按键+数码管键入系统 | 基础必做 | 5 | 第 12 周 |
| 二 | PWM 呼吸灯 | 限选二选二 | 5 | 至少 1 个第 12 周，其余第 14 周 |
| 三 | 交通灯（FSM） | 限选 | 5 | 同上 |
| 四 | 数字时钟 | 限选 | 5 | 同上 |
| 五~九 | 电子琴 / 温度计 / VGA / 电压测量 / 简易 CPU | 五选一 | 10 | 第 14 周 |

## 关键要求备忘

- 检测时**随机抽 1 名组员**现场演示 + 按要求修改代码，每人都必须能独立讲解
- 实验 2~4 检查点均含 **Reset 键有效性**、按要求现场修改展示
- 报告需含：方框图/状态图、关键代码说明、Testbench + 带注释仿真波形、FPGA 资源占用、相关 warning 解释、问题与解决
- 代码风格：tab 缩进、注释充分、状态机/计数器/分频器等标准单元可识别、无 latch
